# Otto Icon

Replaces the editor's Otto (auto-play) icon with Quartz's own icon — or with a picture of your own — tinted to whatever color you like.

## Where to find it

Open the Quartz menu in-game and pick **Visuals → Otto Icon** from the sidebar.

## Highlights

- **Custom Otto Image** opens a file picker for any PNG or JPG, and that picture stands in for Otto. The row above the button shows the file you picked, or *Using the built-in cat* when there is none. **Use Built-in Image** puts the bundled cat back.
- **Tint Custom Image** decides whether your own picture is painted with the colors below. It is off by default, so your art keeps its own colors and only dims while auto-play is off — turn it on to have it colored like the built-in icon.
- **Otto Color** and **Offset X** / **Offset Y** for basic placement and tint. The icon dims automatically while auto-play is off.
- **Separate High BPM Color** — use a different color while the level's top BPM is 300 or higher, which is where the vanilla icon normally turns red. Off keeps the normal color always.

!!! tip

    A picture that is not square is fitted into the icon's square slot rather than stretched to fill it, so tall or wide art keeps its proportions.
