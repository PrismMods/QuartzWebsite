# Features tab

Every Quartz feature ships inside the mod — there is nothing to download or install separately. The **Features** tab is where you choose which ones run. A feature that's off is fully unloaded, so it costs nothing while you aren't using it, and turning it back on brings back every setting you had.

## Where to find it

Open the Quartz menu in-game and select **Features** in the sidebar. Its first tab is **Features**; **Addons** sits beside it (see [Addons](addons.md)).

## Turning features on and off

The page lists features grouped by the sidebar tab they live in — **Overlay**, **Gameplay**, **Visuals**, **Tweaks**, **Editor** and **Others**. Each group is a section you can fold open or shut, and its header shows how many of its features are on out of how many there are.

Every feature row has a switch and an **Open** button:

- **The switch** loads or unloads the feature immediately. Its pages come and go with it, and nothing it changes in the game stays active while it's off.
- **Open** jumps straight to that feature's settings.

Some features build on others — the overlays need **Overlay Core**, for example. Turning a feature on also turns on whatever it needs, and turning one off also turns off everything that depends on it, so you never end up with a feature that can't run.

!!! tip "Finding a feature"
    Type into **Filter features** at the top to narrow the list. Only sections with a match stay open, and clearing the box puts them back the way they were. With the menu in Korean you can type initial consonants instead of whole words — ㅋㅂㅇ finds 키뷰어.

## Hiding a whole tab

The switch on a section's header hides or shows that tab in the sidebar. The features inside keep running; it only tidies the sidebar. To actually stop a feature, use its own switch.

## On each feature's page

- Every feature page starts with a **Use this feature** switch, the same one as on the Features tab, so you can turn a feature off from where you're already looking at it.
- A feature that's off keeps its tab in the sidebar. Opening it shows that it's off and a **Turn On** button. If it needs another feature that's also off, the page says which one, and **Turn On** switches both on.

!!! note "Coming from an older Quartz"
    Your setup carries over: the features you had installed and switched on stay on, and the rest start off. A feature you had switched off on its own page is switched off here instead.
