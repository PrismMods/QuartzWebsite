# Tweaks

A grab-bag of small gameplay and menu adjustments that don't fit under a bigger feature, plus Special Days for A Dance of Fire and Ice's seasonal events.

## Where to find it

These are four separate features, each with its own switch in the [Features tab](features-tab.md). **Tweaks** (the **General** page), **Special Days**, and **Main Menu** are pages on the **Tweaks** tab; **Visual Tweaks** — the settings that change how planets and tiles look during play — is a page on the **Visuals** tab.

## Tweaks (the General page on the Tweaks tab)

- **Disable Auto Pause** — while auto-play is on, the game normally pauses itself (e.g. when the window loses focus); this blocks those automatic pauses. Pausing manually still works.
- **Block Scroll While Playing** — ignores mouse-wheel input while a level is playing, so an accidental scroll can't affect the run.

## Special Days (its own page on the Tweaks tab)

The game turns on its Halloween look during Halloween week and its April Fools jokes in early April. **Halloween** and **April Fools** each pick how that works:

| Option | What it does |
|--------|--------------|
| **By date** | The default — the game decides from the calendar, as usual. |
| **Always on** | The event runs whatever the date, even before you have cleared the first world. |
| **Always off** | The event never runs. |

Changes show after the next scene load.

## Main Menu (its own page on the Tweaks tab)

- **Disable Menu Music** mutes the title/island-select theme; **Custom Menu BPM** sets the menu rabbit's two speeds instead of the default 1x/2x (re-open the menu to apply).

## Visual Tweaks (on the Visuals tab)

- **Remove All Checkpoints** — strips checkpoint icons and behavior from the level; dying always restarts the run. Turning this back off needs a level reload to bring the icons back.
- **Remove Ball Core Particles** — removes the planets' core and spark particles.
- **Disable Tile Hit Glow** — suppresses the glow flash a tile gets when a planet lands on it.
- **Remove Planet Glow** — hides the glow sprite drawn around the planets.
