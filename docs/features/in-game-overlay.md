# In-Game Overlay Fonts

Applies the font you've picked for Quartz's own UI to A Dance of Fire and Ice's native per-hit judgement popup, so your chosen font shows up during play, not just in the mod's menu.

## Where to find it

Open the Quartz menu in-game and pick **Overlay → Judgement** from the sidebar, then find **Judgement Popup Font**.

## Highlights

- **Judgement Popup Font** — the per-hit rating popup ("Perfect!"/"Early!"). Off by default. Turning it on uses whichever font you've selected for the mod, and a **Font Size** slider scales just the popup.

!!! note
    The **Judgement Popup Font** only re-fonts the per-hit rating popup. It's separate from the [Judgement](judgement.md) overlay, which shows accumulated hit counts.
